# H

一個規劃中的個人 Web 工具網站。以多網站編號轉換為核心，預計整合歷史記錄、收藏、純碼表、紀錄查看與 GitHub 同步。

> **目前狀態：規劃階段，尚未開始正式實作。**

## 預計功能

- 多網站編號轉換：自動判斷或手動選擇來源、產生網址、複製與開啟。
- 歷史記錄：保存轉換紀錄並支援搜尋與管理。
- 收藏：保存常用轉換結果或網址。
- 純碼表：開始、暫停、繼續、結束保存；離開網站後可還原；提供完整紀錄查看。
- GitHub 同步：將個人歷史、收藏與碼表紀錄同步至雲端。
- 使用體驗：響應式介面、主題設定，並評估 PWA 支援。

## 開發原則

- 先驗證技術與同步授權方案，再展開實作。
- 本機資料優先，雲端同步失敗不能造成資料遺失。
- 不在前端程式碼中放入 Token 或其他私密憑證。
- 核心邏輯模組化、具備測試，並照顧手機使用體驗。
