## 已有功能

- Astro、Svelte 5、TypeScript、Tailwind CSS 4 網站架構。
- 響應式導覽與淺色／深色／系統主題。
- 編號轉換器、多來源網址產生、歷史紀錄、收藏、搜尋與排序。
- IndexedDB 本機保存、純碼錶與時間統計。
- JSON 備份匯入／匯出，匯入資料會驗證 schema、欄位、ID、URL 與筆數上限。
- Cloudflare Worker 手動同步，包含資料驗證、合併、刪除標記及 GitHub SHA 衝突重試。
- CI 執行型別檢查、測試與建置；網站與 Worker 有部署流程。

## 接下來只保留兩項工作

### P0：明確處理同步資料安全性

目前 `data/sync.json` 位於公開儲存庫 `tsai97216/h`，內容可被任何人讀取；Worker 的 Origin 檢查與限流不等於身分驗證。

- 在解決之前，不要把密碼、私人備註或其他敏感資料放進同步資料。
- 若需要私密同步，另立明確工作：遷移到私人儲存位置、建立真正的授權機制，再驗證部署與資料遷移。
- 這是尚未解決的安全限制，不可因 CI 通過而標記完成。

### P1：進行一次真實雙裝置驗收

只驗證現有核心流程，不再先行擴寫新的假設性測試。

- [ ] 裝置 A 新增收藏並同步，裝置 B 同步後能看到。
- [ ] 裝置 A 更新同一網址的收藏，裝置 B 同步後不產生重複項目。
- [ ] 裝置 A 刪除項目並同步，裝置 B 同步後不會復活。
- [ ] 同步期間本機資料有變動時，不會以舊快照覆蓋新資料。
- [ ] 網路或 Worker 失敗時，本機資料仍保留，介面不顯示同步成功。

驗收結果要記錄實際裝置、操作步驟與結果。未實測的項目保持未完成，不得以單元測試代替端到端驗收。
