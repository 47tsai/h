# 介面與來源規劃

本文件保留尚未完全定稿的介面與來源規劃。現有功能以 `src/components/AppShell.svelte` 及 `src/lib/` 中的實作為準。

## 主要區域

- 編號轉換
- 歷史紀錄
- 我的收藏
- 碼表與紀錄
- 設定與資料管理

## 互動原則

- 優先減少完成常用操作所需的步驟。
- 手機窄螢幕須保留清楚的輸入、結果與操作區。
- 空狀態、錯誤、成功及載入狀態應有明確回饋。
- 主題支援淺色、深色與跟隨系統。
- 同步只由設定頁的按鈕主動發起，不要求輸入同步密碼。

## 來源規則

每個轉換來源都應明確定義：

- 來源識別碼與顯示名稱。
- 可接受的輸入格式。
- 編號驗證規則。
- 產生目標網址的方式。
- 不支援或無效輸入時的回饋。

目前來源規則位於 `src/components/AppShell.svelte` 的 `converterSources`。後續可視實際維護需要拆分成獨立模組；未確認的來源規則不可假設為正確。

## 同步相關

- 設定頁提供一鍵手動同步。
- 前端透過 `PUBLIC_SYNC_WORKER_URL` 指向 Worker。
- GitHub Token 只由 Worker 使用。
- 目前同步資料存在公開儲存庫，Origin 檢查不是使用者身分驗證。需要保護私人資料時，必須先調整儲存位置及授權方式。
