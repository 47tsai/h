# 個人工具網站規劃

本文是需求與方向備忘錄，不代表每項內容都已實作。現況以程式碼及 [實作路線圖](IMPLEMENTATION_ROADMAP.md) 為準。

## 功能範圍

- 多來源編號與網址轉換。
- 歷史紀錄與收藏。
- 純碼錶及時間統計。
- 主題切換與響應式介面。
- 本機資料保存與 JSON 備份。
- 手動雲端同步。

## 技術現況

- 前端：Astro、Svelte 5、TypeScript、Tailwind CSS 4。
- 本機資料：IndexedDB。
- 網站部署：GitHub Pages。
- 同步服務：Cloudflare Worker 代理 GitHub API。
- 詳細技術選擇見 [TECHNICAL_DECISIONS.md](TECHNICAL_DECISIONS.md)。

## 使用原則

- 以個人實際使用為主，不為了展示或公開介紹而增加不必要的功能。
- 常用操作保持直接，手機與桌面都能使用。
- 本機功能不應依賴雲端服務才能工作。
- 同步只能由使用者主動觸發。
- 不將 GitHub Token 放入前端程式或瀏覽器儲存。
- 目前同步檔案位於公開儲存庫，內容可被公開讀取；在改成私人儲存與真正的授權機制之前，不放入敏感資料。

## 待處理事項

1. 處理同步資料的公開性與存取控制。
2. 持續整理轉換器來源規則與 UI 元件。
3. 確保匯入、匯出及同步錯誤不會造成資料遺失。
4. 只有在實作狀態改變時更新規劃文件，避免把構想誤寫成已完成。
