# 個人工具網站規劃

更新日期：2026-10-13

本文記錄產品範圍與維護原則。實作狀態以程式碼、CI 及 [實作路線圖](IMPLEMENTATION_ROADMAP.md) 為準。

## 功能範圍

- 多來源編號與網址轉換。
- 歷史紀錄與收藏。
- 純碼錶及時間統計。
- 主題切換與響應式介面。
- 本機資料保存與 JSON 備份。
- 使用者主動觸發的手動雲端同步。

## 技術現況

- 前端：Astro、Svelte 5、TypeScript、Tailwind CSS 4。
- 本機資料：IndexedDB。
- 網站部署：GitHub Pages。
- 同步服務：Cloudflare Worker 代理 GitHub API。
- 詳細決策見 [技術決策紀錄](TECHNICAL_DECISIONS.md)。

## 使用原則

- 以個人實際使用為主，不為了展示而增加不必要的功能。
- 常用操作保持直接，手機與桌面都能使用。
- 本機功能不應依賴雲端服務才能工作。
- 同步只能由使用者主動觸發。
- GitHub Token 不得放入前端程式或瀏覽器儲存。
- 目前同步檔案位於公開儲存庫，內容可被公開讀取；在完成私人儲存與真正授權之前，不放入敏感資料。

## 目前計畫

1. **安全限制優先：** 決定是否將同步資料移至私人儲存庫並實作真正授權。這是未解決事項，不可誤標為已完成。
2. **完成現有功能驗收：** 依 [實作路線圖](IMPLEMENTATION_ROADMAP.md) 完成真實雙裝置同步檢查。
3. **只修正有證據的問題：** 不持續新增假設性的同步邊界修正或無明確目標的重構。

## 計畫更新注意事項

- 每個新工作必須寫明：問題證據、預期行為、驗收條件及可能影響的資料。
- 自動化測試通過只能證明測試覆蓋的情境通過，不能宣稱真實裝置驗收已完成。
- 部署成功代表版本已部署，不等於所有使用情境均已驗證。
- 若沒有重現問題、驗收失敗或新的明確需求，保持現狀，不要為了「繼續」而製造待辦。
- 完成項目需記錄驗證依據；未驗證項目明確標示待驗收。
