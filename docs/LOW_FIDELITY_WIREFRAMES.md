# 低擬真介面備忘

這份文件是介面方向參考，不是現有畫面的逐像素規格。實際介面以目前網站為準。

## 導覽

- 編號轉換
- 歷史紀錄
- 我的收藏
- 碼表
- 設定

## 編號轉換

- 輸入編號或識別碼。
- 可選擇自動判斷或指定來源。
- 顯示產生的網址及複製、開啟、分享等操作。
- 無輸入、無匹配來源或操作失敗時，顯示簡短提示。

## 歷史紀錄

- 搜尋與排序。
- 顯示來源、網址及最後操作時間。
- 提供開啟、複製、分享、收藏及刪除操作。
- 空列表時顯示簡潔的空狀態。

## 我的收藏

- 搜尋、排序、編輯標題與備註。
- 提供開啟、編輯及移除操作。
- 避免相同網址被重複收藏。

## 碼表

- 開始、暫停、繼續與停止。
- 顯示經過時間。
- 已完成紀錄可搜尋、排序與刪除。
- 顯示今日及累計時間統計。

## 設定

- 主題：跟隨系統、淺色、深色。
- JSON 備份匯出與匯入。
- 手動雲端同步按鈕、同步中狀態、成功或錯誤提示。
- 不需要同步密碼欄位。

## 資料與隱私提示

本機資料由瀏覽器保存。手動同步會將支援的資料送至 Cloudflare Worker，再寫入設定的 GitHub 檔案。目前該儲存庫是公開的，因此同步文件內容可被任何人讀取。介面與文件不可暗示這是私人雲端儲存，也不可將 Origin 檢查描述成使用者登入或授權。

## 介面原則

- 手機上優先保留主要操作，不讓次要資訊擠壓輸入與結果。
- 清楚呈現載入、成功、失敗與空狀態。
- 破壞性操作應有確認或可復原方式。
- 視覺細節可以迭代，但不能以裝飾犧牲可讀性與觸控操作。
