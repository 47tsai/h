# 低保真介面草圖

> 狀態：規劃中。本文件描述資訊層級與互動，不代表最終視覺稿或已開始實作。

## 1. 共通版面

### 桌面版（建議起始寬度：≥ 960px）

```text
┌────────────────────────────────────────────────────────────────┐
│ H / 專案名稱              導覽：轉換器 歷史 收藏 碼表 設定  ☼  │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│                         目前頁面標題                           │
│                    一句簡短的功能說明                           │
│                                                                │
│                         主要工作區                             │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

- 內容區限制最大寬度，避免超寬螢幕上文字與表單被拉得過長。
- 導覽需標示目前所在頁面；同步狀態放在設定或次要狀態區，不搶主要操作。
- 轉換器與碼表各自聚焦一項主要任務，不在首頁堆疊所有功能。

- 窄螢幕優先採簡潔底部導覽；若主要頁面數量或可用寬度不合適，再改用可收合選單。
- 重要按鈕要有足夠觸控面積；避免把刪除等破壞性操作放在最容易誤觸的位置。
- 鍵盤彈出時，輸入欄與提交按鈕仍應可操作。

## 2. 首頁／轉換器

```text
┌─────────────────────────────────────────────┐
│ 編號轉換器                                  │
│ 輸入編號或網址                              │
│ [____________________________________] [清除]│
│ 來源：[自動判斷                         ▾]   │
│                                             │
│ [產生網址]                                  │
│                                             │
│ 結果                                        │
│ [https://…___________________________]      │
│ [複製] [開啟] [分享] [☆ 收藏]               │
│                                             │
│ 最近使用                                    │
│ • 來源／編號／時間                 [重新開啟] │
└─────────────────────────────────────────────┘
```

互動規則：
- 空白輸入時不顯示成功結果。
- 支援自動判斷時，顯示判斷出的來源；手動指定來源後則尊重使用者選擇。
- 結果區需可選取文字，複製功能失敗時仍能手動複製。
- 驗證失敗時在輸入欄附近說明原因，不只顯示顏色或通用錯誤。
- 最近使用清單只顯示少量項目，完整清單連至歷史記錄。

## 3. 歷史記錄與收藏

```text
┌─────────────────────────────────────────────┐
│ 歷史記錄                       [搜尋_____]  │
│ 排序：[最新優先 ▾]   來源：[全部 ▾]          │
│                                             │
│ 來源 A   編號／網址                 2026/.. │
│          [開啟] [複製] [收藏] [刪除]         │
│ ─────────────────────────────────────────── │
│ 來源 B   編號／網址                 2026/.. │
│          [開啟] [複製] [收藏] [刪除]         │
│                                             │
│                     [載入更多／分頁]         │
└─────────────────────────────────────────────┘
```

- 收藏頁沿用相同的清單閱讀方式，但只提供收藏相關操作。
- 搜尋至少涵蓋來源、輸入值與網址。
- 空狀態需提供清楚的下一步，例如返回轉換器。
- 清除全部或大量刪除前要確認；單筆刪除應避免誤觸。
- 刪除歷史記錄不得連帶刪除同一項目的收藏。

## 4. 碼表

```text
┌─────────────────────────────────────────────┐
│ 碼表                                        │
│                                             │
│                 00:12:34.56                 │
│              ● 計時中／已暫停               │
│                                             │
│             [暫停] [結束並保存]              │
│                                             │
│ 最近紀錄                      [查看全部 →]  │
└─────────────────────────────────────────────┘
```

- 開始前顯示「開始」；計時中顯示「暫停」及「結束並保存」；暫停時顯示「繼續」。
- 結束並保存後建立完成紀錄，名稱由開始日期與時間自動產生，不提供任務名稱或分類。
- 使用者離開頁面再返回時，從持久化狀態恢復計時；顯示的時間由時間戳計算，不依賴背景每秒執行。
- 重要狀態需有文字標示，不能只用顏色或動畫表示。

## 5. 碼表紀錄

```text
┌─────────────────────────────────────────────┐
│ 碼表紀錄                   [搜尋________]   │
│ 日期：[起始日] 至 [結束日]   排序：[最新 ▾]  │
│                                             │
│ 今日累計  01:23:45    全部累計  12:34:56     │
│                                             │
│ 2026/.. 09:30 開始                          │
│ 2026/.. 10:05 結束   計時 00:31:20 [詳情]   │
│ ─────────────────────────────────────────── │
│ 2026/.. 14:10 開始                          │
│ 2026/.. 14:25 結束   計時 00:12:00 [詳情]   │
└─────────────────────────────────────────────┘
```

- 詳情顯示開始、結束、各次暫停區段與累計有效時間。
- 統計只加總有效計時時間，不把暫停時間計入。
- 刪除紀錄前確認；同步時需保留刪除標記，避免舊紀錄被重新下載後復活。

## 6. 設定

設定頁分成清楚的區塊：

1. **外觀**：淺色、深色、跟隨系統。
2. **同步**：未連結／已連結、最後同步時間、待同步數量、錯誤及重試。
3. **資料管理**：匯出、匯入、清除本機資料；破壞性操作須確認。
4. **隱私與說明**：說明哪些資料留在本機、哪些資料會同步至 GitHub，以及如何撤銷授權。

不得在介面中要求使用者把長期有效的 GitHub Token 貼入公開前端表單。
